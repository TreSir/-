## 0. 三条已定案的前提

### 0.1 寄件人不解释【定案】

> **谁把黑页寄给主角，全篇不给答案。**

推论（写剧情时必须遵守）：

- 可以查到"寄件人存在"——第一页的字迹、那张无主笔记的拓印、同一只手的笔迹。
- 不可以查到"寄件人是谁"。任何一条线索、任何一个角色、任何一个结局都不能指向他的身份。
- 玩家如果推理出答案，游戏不给确认。答案留在页角之外。
- 因此本作的悬念结构是：**案件线全部可解释，笔记线永不解释。**两条线的信息预算不同，写作时不要混用。

### 0.2 落笔的代价只有"人的怀疑"【定案】

> **没有寿命、没有反噬、没有世界自动纠正。代价全部来自具体的人。**

理由：没人会相信"有人凭空空降死亡"。所以第一笔之后，周围人的反应不是"闹鬼了"，
而是最朴素的一种——**"为什么你刚问完这个人？"**（这句已经在 `codex.json` 里，由林墨说）。

代价只从两个方向来：

| 来源 | 机制 | 现状 |
| --- | --- | --- |
| 林墨 | `linmo_suspicion` 累积 | 【实装】三名角色死亡分别 +35 / +25 / +20 |
| 与死者或主角关系近的人 | 回避、记录、拒绝配合、把话说变 | 【提案】第二/三章需要具体动作 |

怀疑的后果必须是**调查手段变少**，不是数值惩罚：某些 `actions` 因怀疑过高而不可用、
某些人不再给线索、林墨开始反过来问主角。这与"舍弃行动点系统"（架构 §18）不冲突——
限制的来源是**人与人之间的关系状态**，不是抽象资源。

### 0.3 许妍是被保护的失踪者【定案】

> **她全程不正面出场。**玩家认识她的全部途径：聊天记录、监控、电话里的呼吸和半句话、
> 她留下的证词、图鉴里一条条解锁的档案。

- 她是麦格芬，也是主角的动机。不给她独立行动力，不让她自己也在写。
- **但她仍然是可写目标**（`identity: 100`）。这不是漏洞，这是本作最狠的一下：
  架构 §20 说"满足规则的角色原则上都可以被杀"，而玩家明知她在躲、明知有人在她身边保护她，
  手上的规则照样成立。写她 = 亲手拿掉她唯一的屏障。
- 她死后走 B 类"可处理的关键死亡"（架构 §24）：`testimony_lost` → 旧手机残缺语音 →
  案件仍可完成，只是真相降级。【实装】

## 1. 一句话

一个收到"写下真实姓名就能杀人"的黑色笔记本的普通人，在追查前女友失踪的过程中，
逐渐确认自己每落一笔都在接近真相——但**接近的是谁的真相，这本笔记永远不告诉他**。

## 2. 主题

- 表层：审判的权力该交给谁。
- 中层：**每一次"该死"都是有人教你的。**玩家以为在做判断，其实一直在填别人留好的空行。
- 底层：不能问出答案的那个东西，才是这本书真正在写的东西。

## 3. 黑页的规则【实装文本 + 定案解释】

1. 只写**真实姓名**，写的人必须**见过那张脸**、认得那个人。（第一页原文，对应 `identity`／`discovered`）
2. 笔记会**先自己写下一个名字和时间**。序章第二页的"周启明 23:47"不是主角写的。
3. 写完那一笔之后，第三页从纸纤维里渗出墨色："下一次。""由你来写。"——它把选择权推回给持有者。
4. 死亡延迟结算，次日兑现。【实装：`pending` 机制】
5. 执行前自动存检查点，关键因果断裂时可回溯到落笔之前。【实装：架构 §27】

**规则里刻意不留的东西**：笔记从哪来、第一页谁写的、它为什么选这个人。这三问不给答案。

序章有一处文本要护住：第一页"字迹不像印刷，更像有人刚用钢笔写上去"——
它证明**有一只手在现场写**，但全书不让这只手的主人现身。这是钩子，不是伏笔回收点。

## 5. 幕结构

架构 §16 的骨架：序章 → 案件 01 → Hub → 公共剧情 → 案件 02 → Hub → 案件 03 → 最终主线。

> 下面各章描述的是**内容**。哪一节拍属于主干、哪一节拍属于枝叶、章末必须归一成什么状态，
> 以 **§7 主分支（金线）** 的节拍表为准。

### 序章《黑页》【实装】

雨夜。无寄件人的包裹。预写的名字。一个多小时的对峙——**什么都没发生，主角笑了一下**，
然后手机推送改写了标题，死亡时间与笔记一致。次日清晨，许妍的来电里只有急促呼吸、
一声"别……"和手机落地的响。

功能：证明笔记是真的；把主角的动机焊死在许妍身上；给玩家第一条规则直觉（"我认不得的人，它替我写"）。

### 第一章《她失踪了》【实装】

调查链：公交站监控 → 员工证"陈东" → 林墨查出身份只有八年 → 晨曦福利院火灾旧照 →
陈东＝周文远 → 许妍主动联系他，她在躲，因为有人要拿她父亲留下的资料，那些人和恒生生物有关。

**本章的道德陷阱**：满足规则的只有周文远，而他恰恰是保护许妍的人。
系统层面完全允许落笔，剧情层面它是错的——**这个错位就是本作全部张力的来源，不要为了心疼玩家去堵它**。

**暗线**：林墨记住了主角问过的每一个名字。第一章就已经在给它自己埋怀疑值。

**收口**：`chapter1_end` 要求林墨活着；五结局见 §6。隐藏结局的入口是福利院移交清单上
那张**无主笔记的拓印**（"名字不是终点"）——第一章结尾就把主线钩子交给玩家，但只给钩子，不给答案。

### Hub（章节之间）【提案，未实装】

出租屋。不是休息点，是主角自己说服自己的地方。承载四件事：

1. 黑页的试探——在 Hub 里落笔，代价按 §0.2 结算，后果延迟到次日。
2. 图鉴回看：让玩家看见自己已经知道了多少，同时看见**许妍那一栏永远缺最后一行**。
3. 许妍的碎片联络（间接、无 face time，遵守 §0.3）。
4. 下一封没有寄件人的东西——**Hub 是笔记存在感最强的地方，也是唯一的地方。**

### 第二章《该死的人》【提案】

表面：一个与启明资本集资案相关的人死了，警方按普通命案办。主角认出死法与黑页一致——
有人在他之前，或者在他之后，也在写。

给玩家的现实信息：死者当年是晨曦福利院的资方联系人；十三年前那场火不是意外；
启明资本是恒生生物早期的资金通道。

**本章的功能是把"怀疑"变成可感知的代价**（§0.2）：主角已经用过笔记，所以这一章开始，
配合他的人变少了，林墨的问话变长了，某个调查动作直接不可选。

**本章的道德陷阱升级**：笔记预写的下一个名字，是一个玩家也会认为该死的人。
主角第一次"主动"落笔的代价在这里兑现——不是天罚，而是很世俗的一种：
那个人死了，可他手里那份能定罪的证据也跟着进了火里。**正义的代价是正义本身变少了。**

留痕：第二只手的证据只留笔迹与快递单，不留人。【受 §0.1 约束：不得指向寄件人身份】

### 第三章《保管人》【提案】

许妍父亲留下的资料终于打开。里面不是产品，是**一份名单**——晨曦福利院的孩子被系统性转移、
身份被注销或重建。周文远是唯一成功的样本；许妍的父亲是名单的保管人，也是**第一个试图用这本笔记阻止名单的人**。

注意边界：这里解释的是**人与人的阴谋**，不解释笔记。父亲怎么得到笔记、他写没写完，
都停在"有人写过"这一层。

**本章把追踪者推上前台**：林墨摊牌。他调查的不是失踪案，是"每一个问过这些名字的人"。
主角第一次意识到，从序章那一个名字起，他就一直在被看着——这才是全篇真正的惩罚，
而且它完全符合"没有人相信超自然"的世界观。

**玩法与剧情在此对齐**：架构 §19–§30 的整套死亡笔记压力测试（可写 → 检查点 → 断链 → 回溯）
用林墨来教最完整。他是本章唯一"写了就断"的人，玩家会主动试一次。让他试。

### 最终主线《页角之外》【提案】

不是对决，是**最后一个名字写不写**。三个方向已经写死在 `endings.json`：

- **不合上**（`writes>0` + `keep`）→ 审判者：笔记留在伸手就能碰到的地方，"下一个名字会是谁"。
- **合上**（`writes>0` + `seal`）→ 错误的正义：新闻把一切写成偶然，你知道不是。那些再也无法回答的问题留在调查笔记里。
- **合上且干净**（`writes==0` + `seal` + 真相度足够）→ 合上黑页：没有人因你而死，活着的人还有机会开口。
- **低信息**（兜底）→ 未完的调查：你没得到足够解释一切的答案，黑页也没替你决定。
- **隐藏**（`writes==0` + `hidden` + 真相度足够 + `seal`）→ **页角之外**：
  你封存黑页，却留下了那张拓印。第一次，你开始调查这本笔记，而不是它要你调查的人。

隐藏结局是续作的门，**但它开门之后问的仍然是"谁在写"，不是"谁在写"**——
它是把问题正式宣布成主线，而不是把问题回答掉。

## 6. 结局矩阵（与 `endings.json` 一一对应）

| 结局 | 条件 | 优先级 | 玩家带着什么离开 |
| --- | --- | --- | --- |
| 页角之外（隐藏） | `hidden` ∧ `writes==0` ∧ `decision=seal` ∧ `zhou.truth>=80` | 100 | 笔记是下一个案发现场 |
| 错误的正义 | `writes>0` ∧ `decision=seal` | 90 | 你审判了，但真相变少了 |
| 审判者 | `writes>0` ∧ `decision=keep` | 80 | 你开始期待下一笔 |
| 合上黑页 | `writes==0` ∧ `decision=seal` ∧ `zhou.truth>=80` | 70 | 你查清了，且没有越界 |
| 未完的调查 | 兜底 | 0 | 你没看够 |

结构上要注意的一点：**两个"干净"结局的优先级高于两个"落笔"结局**，而隐藏结局要求一条
第一章里藏在文档动作里的支线（`notebook`）。这意味着：**最完美的路线是杀得最少的路线。**
这条路线不是五条中的一条，它就是主干——见 §7。

这跟"死亡笔记允许玩家真正破坏剧情"（架构 §28）不矛盾——允许，但代价是结局降档、
以及怀疑累积让后面的调查手段变少。

## 7. 主分支（金线）【定案】

先钉结局，再往上挂节点。

### 7.1 最好的结局是哪一个

**《页角之外》**（`endings.json` 里 priority 100 的那条）。

它不是四条结局之外的第五条平行线——**它就是主干**。其余四条全部是主干的**降级出口**：

| 出口 | 相对金线少了什么 |
| --- | --- |
| 合上黑页 | 少了页角物（没做 `notebook` 那个文档动作） |
| 错误的正义 | 少了"不写"（写过一笔） |
| 审判者 | 少了封存 |
| 未完的调查 | 什么都没查够 |

所以金线的定义不是"另一种玩法路线"，而是**这条线本来就该走的样子**。

### 7.2 金线的五条判据

跨全篇成立，不是一章内成立：

1. **`writes == 0`** —— 一笔画不写。系统始终允许，玩家选择不。
2. **关键人物 `truth >= 80`** —— 真相打满，不靠笔补。
3. **`decision == "seal"`** —— 结尾封存。
4. **三章各一件页角物** —— 每章都拿到"有另一只手在写"的实物痕迹（§7.4 里的 `page_n`）。
5. **不断链** —— 林墨活着，且调查手段没有被怀疑锁死（§0.2）。

一句话版本：

> 你一次都没有落笔，你还是把该死的人、该藏的人、该查的事全查清了。
> 名单公开了，许妍安全了，你没有去见她。
> 笔记锁进抽屉，那张拓印留在你手上。
> 你开始调查它。

### 7.3 金线节拍表

| 章 | 入口状态 | 主干节拍（按依赖顺序） | 章末必须成立 | 页角物 |
| --- | --- | --- | --- | --- |
| **序章**【实装】 | — | 包裹 → 预写的名字 → 查证 → 等待 → 应验 → 断线的电话 | `prologue.completed`、`black_page_real`、`zhou_qiming_dead`、`xu_unreachable` | — |
| **第一章《她失踪了》**【实装】 | `case.missing=active` | `camera`（小游戏）→ `badge` → `archive`（要林墨）→ `photo` → **`testimony`（第三天之前）** → `notebook` → `cooperate` → 定案 | `result=explained`、`zhou.truth>=80`、`hidden`、`linmo.status=normal`、`writes=0` | 福利院移交清单上的**无主笔记拓印**："名字不是终点" |
| **第二章《该死的人》**【提案】 | `case_002=active` | 死法与笔记一致 → 死者＝当年福利院的资方联系人 → 启明资本是恒生生物的资金通道 → **笔记预写他**（选择点）→ 他死于另一只手 → 笔迹比对 | `result=explained`、死者身份真相满、`page_2`、账目证据在手、`writes=0` | 第二只手的笔迹，与序章第一页同源（**不得指向寄件人是谁**） |
| **第三章《保管人》**【提案】 | `case_003=active` | 打开父亲留下的资料 → 名单（转移／身份注销与重建）→ 父亲是保管人，也是第一个用它的人 → **林墨摊牌**（最大诱惑：写他）→ 选择 → 把查到的交出去 → 封存 | `result=explained`、名单公开、`person.xu.status=safe`、`page_3`、`linmo.status=normal`、`decision=seal`、`writes=0` | 名单"保管人"一栏的空白签名／序章字迹原件对照 |
| **终章**【提案】 | 三件页角物齐 | 不作案。把三章的痕迹并排放到桌上，确认"有一只手比我们先动，而且它还在写" | 终局条件判定（§7.5） | — |

第一章那一格要单独记住一件事：**金线是限时的**。`actions.testimony` 要求 `day<=3`，
而 `event.deadline` 在第四天把证词路线关掉。这个限时符合架构 §18 的例外条款——
压力来自"约定窗口过了"，不是抽象行动点。第二、三章沿用同一条：**金线的稀缺性来自时间，不来自次数。**

### 7.4 枝怎么拆、怎么接回来

**归一原则（这条决定思路会不会再乱）：下一章只读章末状态，不读你走过哪条路。**

每章章末必须归一的三样：`case.result`、关键人物 `status`、页角物布尔。只要这三样成立，
下一章的开场文本可以有几个变体，但**走向同一个主干**。

三种枝：

| 枝 | 处理 | 已实装的例子 |
| --- | --- | --- |
| **降级枝** | 少证据 / 少页角物 → 主线照走，结局降档 | `result=partial`、`uncertain` 结局 |
| **替代枝** | B 类关键死亡 → 一个短替代动作接回主干（架构 §24 B） | 林墨死后 `archive_public` 顶替 `archive` |
| **断链枝** | C 类死亡 → StoryBroken → 回溯到落笔之前 → **回到主干原位** | `chapter1_end.gate` 要求林墨活着 |

断链枝要特别说清楚：**回溯不留痕迹，也不要在剧情里惩罚回溯。**
玩家试了、看了后果、退回来，这是架构 §28 给的权利；写进剧情的话，玩家就不敢试了，
死亡笔记当场退化成摆设。

硬约束：任何枝都不得违反 §0 三条定案。支线尤其不能顺手回答"寄件人是谁"——
它是全篇唯一不许被消费的悬念。

### 7.5 金线在数据层还缺什么

这些不是新玩法，是让金线**跑得通**的最小补齐项：

1. **终局条件集。**现在 `endings.json` 五条全是"首章结束"尺度的，金线跨三章。
   需要把章末结局与全篇终局分开（加 `scope: chapter|final`，或拆成 `endings.json` / `final_endings.json`）。
2. **页角物拆成三个布尔。**现在只有一个 `hidden`，三章共用会互相覆盖，
   第二章拿到的痕迹会把第一章的抹掉。建议 `page_1`／`page_2`／`page_3`，`hidden` 变成派生值。
3. **`person.xu.status` 缺一个"安全"枚举值。**金线终局要求她被确认安全但不出场。
4. **`erosion` 与 §0.2 冲突**（见 §8 约束 2）。它现在是悬空计数器：`death_note_system.gd:52`
   每次写对 +1，没有任何条件读它。要么删，要么改名成社会性的东西并接进 `requires`。
5. **第二、三章的全套数据**：`cases.json` 的 `case_002/case_003`、对应 `actions`／`clues`／`people`／`codex`。
6. **`finish_case()` 是首章专用的**（`investigation.gd:343`，`choice` 直接写全局 `decision`）。
   金线跨三章，这里有个内容层的规定要跟：**"封存 / 留手边"全篇只问一次，放在终章**——
   它是主角对笔记的最终态度，不该每章重来一遍，否则第三章的选择会被读成第三次反悔。
   每章末问的是另一件事：**这一章查到的东西交不交给林墨**。两者不要混用同一个旗标。

## 8. 写作约束清单

新增任何剧情数据前，先过这四条：

1. **不解释笔记。**线索可以证明"有手在写"，不可以证明"那是谁"。（§0.1）
2. **代价只来自人。**不出现超自然反噬、不出现"世界开始惩罚主角"。写怀疑与关系，不写命运。（§0.2）
3. **许妍不露面。**她的档案可以一条条补齐，最后一行永远空着。（§0.3）
4. **允许写错的人。**不要因为角色重要就在系统层禁止死亡（架构 §20）；用 A/B/C 三类影响承接，
   C 类交给 StoryBroken 与回溯（架构 §25–§27）。堵死错误选项，等于删掉本作的核心玩法。
