## 授权（摘自字体自带的 readme-onryou2.txt）

- 免费使用；**加工进游戏等作品里分发、贩卖都可以**（随游戏发布 / 商用都 OK）。
- **禁止事项：字体文件本身的再配布**（把 `onryou.ttf` 当字体发出去）。
- 商用不强制署名；作者只是「希望」告知用途（邮件，或在站点上写一句 / 挂个链接）。

## 用在哪

只有**剧情正文**用它——对话框的叙述文字与「回顾」列表，入口是
`scripts/black_page/ui_style.gd` 的 `STORY_FONT` / `story()`；
界面控件（按钮、菜单、标签、标题）一律走系统字体。

## 覆盖缺口（重要）

它是日文字体（JIS 第一 / 第二水準），**没有简体专有字形**：正文里约五分之一的字
（东 / 门 / 页 / 说 …）缺字，运行时落到 `story()` 挂的系统字体链（Microsoft YaHei 等）
上兜底——不会出豆腐块，但同一句话里会混着两种字体。
实测：游戏数据里 616 个不重复汉字有 166 个缺，按出现次数约 19%。

## 换字体 / 换回去

改 `ui_style.gd` 顶部的 `STORY_FONT` 指向别的字体文件即可，其余代码不用动；
不用日文字体、回到系统字体的话，把 `notice` 与回顾行上的 `UI.story()` 覆盖删掉。
